# Democrata Bier V2 — Primeira reconstrução

Esta versão preserva o motor do projeto original e refaz a experiência principal.

## O que mudou

- Nova tela de entrada com visual mais premium e a foto da Democrata Bier.
- Nova tela **Início**, com resumo real da receita atual, OG, FG, ABV, IBU, volume, eficiência, maltes e lúpulos.
- Sidebar fixa no desktop com nomes simples: Início, Receita, Brassagem, Água, Problemas, Rótulo e Ficha.
- Navegação compacta para celular.
- Atalhos para iniciar brassagem, nova receita, calculadoras, água e edição da receita.
- O editor antigo continua funcionando e os cálculos existentes foram preservados.
- Vários nomes excessivamente técnicos/"gamificados" foram simplificados na interface.
- Título e descrição do site atualizados para **Democrata Bier • Receitas & Brassagens**.
- Receitas continuam usando a mesma chave de armazenamento local do projeto original.

## PIN

O PIN padrão continua sendo `1984` quando nenhum PIN personalizado estiver salvo.

## Rodar o projeto

1. Instale as dependências com `npm install`.
2. Rode `npm run dev`.
3. Abra o endereço informado pelo terminal.

## Observação

O ZIP original não foi alterado. Esta pasta é uma cópia de trabalho separada.
